# Calculator App

A desktop calculator application built with Python, PySide6, JSON, and Qt Designer. The application provides a clean and user-friendly interface for performing basic mathematical calculations.

# Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division
- Modulus (%) operation
- Decimal number support
- Backspace and Clear (AC) functionality
- Calculation result display
- Calculation history
- Persistent history storage using JSON
- Custom calculator UI designed with Qt Designer
- Windows executable support

# Technologies Used
- Python
- PySide6
- Qt Designer
- JSON
- PyInstaller

# Project Purpose
This project was created to practice Python GUI development, event handling, file handling, and application packaging using PySide6.

# How to Run

- Install the required package:

- pip install PySide6

- Then run:

- python calculator.py

# Windows App

A Windows executable can be created using PyInstaller:

pyinstaller --onefile --windowed calculator.py
